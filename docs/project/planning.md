Per a cada sessió de treball, actualitzar:
- Tasques iniciades i finalitzades.
- Responsable real.
- Bloquejos i dependències.
- Canvis de prioritat.
- Evidències afegides.
- Tasques que passen al sprint següent i motiu.

## Definició de fet (DoD)

Una tasca només es marca com a acabada quan:
1. El canvi s'ha aplicat a l'entorn corresponent.
2. S'ha executat una prova adequada.
3. El resultat s'ha registrat.
4. La documentació s'ha actualitzat.
5. L'evidència no exposa credencials ni dades sensibles.
