# Seguiment dels sprints

Cada sprint hauria de conservar el context de planificació i les proves de què s'ha fet.

## Contingut mínim per sprint

- **Planificació:** objectiu, tasques, prioritat, responsable i criteri d'acabament.
- **Registre de treball:** data, feina realitzada, incidències i següent pas.
- **Resultats:** entregables i proves que es poden reproduir.
- **Revisió:** què s'ha completat i què queda pendent.
- **Retrospectiva:** què ha funcionat, dificultats i accions de millora.
- **Evidències:** enllaços a captures rellevants, logs sanejats o resultats de proves.

- [Sprint 1](sprint-01/README.md) — documentació inicial; cal completar-la amb el diari i les evidències reals.
- Sprint 2 — pendent d'iniciar o de documentar segons l'estat real del grup.
