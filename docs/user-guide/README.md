# Guia d'ús per al client

> Guia inicial. Cal adaptar-la a les pantalles i funcionalitats reals de l'aplicació abans de lliurar-la.

## 1. Finalitat

L'aplicació del projecte té com a objectiu permetre consultar dades d'equipaments educatius de Barcelona. El diari del primer sprint també descriu la intenció de disposar d'una web per consultar i modificar informació de la base de dades; les operacions realment disponibles s'han de confirmar abans de publicar aquesta guia com a definitiva.

## 2. Requisits previs

- Disposar d'accés a la xarxa o entorn on s'ha desplegat l'aplicació.
- Utilitzar un navegador web actualitzat.
- Disposar de l'adreça d'accés facilitada per l'equip administrador.

L'adreça i els permisos d'accés s'han d'afegir quan estiguin confirmats. No publicar adreces internes sensibles en una còpia pública del repositori.

## 3. Accés a l'aplicació

1. Obrir el navegador.
2. Introduir l'adreça de l'aplicació facilitada per l'administrador.
3. Esperar que es carregui la pàgina inicial.
4. Si apareix un error, anotar-ne el missatge i contactar amb l'administrador.

| Funcionalitat | Instruccions | Estat |

## 5. Problemes habituals

- **La pàgina no carrega:** comprovar la connexió i contactar amb l'administrador.
- **La consulta no retorna dades:** revisar els filtres i comunicar el cas a l'administrador.
- **Apareix un error en una operació:** no repetir accions destructives; anotar el missatge i l'hora.

## 6. Contacte i suport

Afegir el canal de contacte acordat pel grup o pel professorat. No incloure dades personals innecessàries al repositori.
